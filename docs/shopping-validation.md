# 商品查询 Agent 验收记录

日期：2026-10-10。使用仓库已有的 ms-swift 4.5.3 容器、Qwen3-1.7B 和 RTX 5090 Laptop 24GB。

| 项目 | 结果 |
| --- | --- |
| 标准库单元测试 | 14 项通过；包括 360 个不同任务世界的示范策略/oracle 对照 |
| 生成数据 | train 1000、val 200、test 200；seed 42 |
| split 隔离 | 商品 ID 不重叠；生成过程自动校验 |
| 全部训练样本真实模板编码 | 通过，最长 970 tokens，平均 762.1 |
| 全部验证样本真实模板编码 | 通过，最长 947 tokens |
| 监督目标 | 工具调用和最终回答参与训练，工具返回不参与训练 |
| 脚本策略在线执行 | 独立 test 集 200/200 成功；不是模型成绩 |
| 原始模型真实工具评估 | val 集前六个任务，严格成功 4/6，答案正确 5/6 |
| 两步 Agent SFT | 独立 seed 43 小数据集（24/6/6）；梯度非零，验证和 checkpoint 保存成功 |
| SFT 显存记录 | 4.12 GiB，micro batch 1，短轨迹 |
| 保存后 LoRA 重新加载 | 同六个 val 任务完成实际工具交互，严格成功 6/6 |

两步 SFT 的训练学习率为 1e-4、梯度累积 1、无 warmup。上述两次模型评估使用同一份任务文件、同一批任务 ID 和同一判定规则。

这只是端到端流程验收，**六条验证数据和两个训练步骤不能证明泛化效果**。正式训练默认使用 1000 条训练轨迹、独立验证集和梯度累积 8；正式训练及完整保留测试集的模型评估尚未运行。

本机生成的任务、轨迹、评估日志和 LoRA 权重保存在忽略提交的 `workspace/shopping/` 中。克隆仓库后可以通过操作指南复现数据和流程；无需下载这些本机产物。

## 奖励语义

这里的成功率包含明确的流程约束：必须按用户条件搜索并查询全部候选商品库存。原始模型验收中有一题答案正确，但漏查库存，判为失败。判定器还检查工具调用是否合法、返回内容能否在环境中重放以及最终 JSON 的字段和类型。

目前只提供可用于强化学习的环境与二元结果奖励，尚未接入 ms-swift 多轮 GRPO rollout/训练插件。
